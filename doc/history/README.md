## Как нумеровать и продолжать

- Сохранять общую нумерацию обучения, не начинать с `day-1`.
- Создавать `day-N/` только при начале занятия по запросу Маши. Внутри — `lesson.md` и `result.md` по шаблонам из `../templates/`.
- При завершении дня добавлять `youtube.md` с названием и описанием ролика по фактическому итогу; показывать его содержимое в диалоге. Это относится и к дням с частичным результатом. Правила — в [youtube.md](../youtube.md). Номер в названии ролика берётся из учебного дня, а не из количества видео на канале.
- Перед созданием проверить указатель и существующие каталоги. Новый номер — следующий после максимального уже выданного номера с учётом исходной границы 17. Сравнивать числа, а не порядок имён файлов. Не перезаписывать существующий день и не выдавать занятый номер повторно.
- В одном диалоге или после перерыва продолжать активный день. Новая календарная дата сама по себе не требует нового номера.
- Если Маша явно завершила день с незаконченной работой, записать частичный результат и перенести конкретный остаток. Следующее занятие получает новый номер; завершение дня не означает освоение навыков.
- После каждого существенного изменения обновлять указатель: активный день, этап работы, следующий шаг и следующий свободный номер. Таблица ниже содержит ссылки на выданные задания и результаты, а не подробный пересказ.
- Если диалог оборвался, восстановить состояние по файлам и последней записи, не придумывать отсутствующие ответы. При расхождении указателя и файлов исправить указатель по фактам; не выбирать наугад между двумя активными днями.
