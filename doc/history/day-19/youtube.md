## Название

День 19. PostgreSQL в Docker и первые шаги с Java и Spring

## Описание

Продолжаю с нуля делать приложение «Английский из 90-х». Сегодня с помощью мужа подготовила базу PostgreSQL в Docker и подключилась к ней из IntelliJ IDEA. Затем вместе с Codex добавляла библиотеки и настройки для подключения Java-приложения к базе. Приложение запустилось, но сохранение данных ещё впереди.

Разбиралась, где находятся Java-пакеты, как создать класс и что означают import, @Component и метод run. По подсказкам написала небольшой компонент с выводом «Маша и код». По пути исправляла скобки, оставшиеся из шаблона настроек, и переносила класс в нужный пакет.

В конце обсудили с мужем и Codex дальнейший план: перейти к сохранению английского слова с переводом, увидеть запись в таблице через IDEA и получить её обратно запросом. Контроллер, сервис, репозиторий и Entity будем разбирать постепенно на этой задаче. Сегодня закончила на подготовке — продолжу в следующем занятии.
