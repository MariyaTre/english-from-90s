## Практика — интерфейс репозитория

Адаптация после затруднения: дано визуальное объяснение «перечень операций / исполнитель / картотека» с соответствием интерфейсу, реализации и БД. Маша верно ответила, что перечень — интерфейс, а для сохранения нужен объект репозитория и выполнение операции; уточнён вызов save. Возобновить практику ниже, не повторяя всё объяснение. Понимание различия после поддержки подтверждено; перенос на свой код ещё предстоит проверить.

Основной навык JPA-REPOSITORY; повторение JPA-MAPPING и CODE-STRUCTURE. Основы проверены: Маша описала один Word как одну строку со словом, переводом и id, назвала Long типом целых чисел. Уточнить, что объект в памяти может ещё не быть сохранён.

Сторонний пример только для объяснения: предполагается существующая Entity Fabric с id типа Long. Разобрать импорт org.springframework.data.jpa.repository.JpaRepository и объявление public interface FabricRepository extends JpaRepository<Fabric, Long> с пустым телом. Объяснить public, interface как описание доступных операций (не экран), имя FabricRepository, extends как наследование операций другого интерфейса, JpaRepository как интерфейс Spring Data JPA, угловые скобки как параметры типов (сущность, тип её id), пустые фигурные скобки как отсутствие собственных дополнительных методов. Реализацию стандартных операций предоставляет Spring Data JPA при запуске; сохранение происходит при вызове операции, не при объявлении интерфейса. Импорт позволяет использовать короткое имя библиотечного типа. Сопоставить с карточкой ткани и операциями учёта; сама база хранит данные.

Маша создаёт интерфейс WordRepository в пакете words рядом с Word через New → Java Class с выбором Interface. По примеру самостоятельно формирует наследование и выбирает оба типа по своему Word. Образец Fabric в проект не переносится. Если импорт не добавлен IDEA, использовать разобранный библиотечный импорт. Полный готовый код WordRepository не выдавать.

Качество: файл WordRepository.java, PascalCase, package соответствует каталогу Word, роль только доступа к данным, правильный импорт JpaRepository, параметры по сущности и типу id. Не добавлять сюда поля english/russian, SQL и HTTP-обработку. Отсутствие сохранённой строки на этом шаге ожидаемо.
