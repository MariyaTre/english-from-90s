## Название

День 20. Создаю класс слова в Java и знакомлюсь с JPA

## Описание

Продолжаю писать «Английский из 90-х» и разбираться в Java с нуля. Сегодня создала класс Word с полями для английского слова, перевода и идентификатора. На примерах с тканями разбирала классы, объекты и поля, пробовала создавать объекты и выбирать имена.

С подсказками добавила аннотации JPA: указала имя будущей таблицы, поле идентификатора и способ получения его значения из базы. По ходу исправляла пробелы в имени поля, забытую точку с запятой и запись настройки в @Table. Подключила Spring Data JPA и Liquibase через Maven.

До создания таблицы сегодня не дошла: SQL-задание оставила на следующее занятие. Пока подготовила описание слова в Java и нужные зависимости — само сохранение слов в базу ещё впереди.
