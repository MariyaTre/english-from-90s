## Название

День 18. Запускаю первый сервер на Java и Spring Boot

## Описание

Продолжаю учиться программированию с нуля и делать приложение «Английский из 90-х». Сегодня повторяла переменные, числа и строки в JavaScript. Разбиралась, почему вычисление второй переменной не меняет первую, что означает camelCase и как незаметная русская буква может изменить имя переменной.

Муж вместе с Codex добавил в проект папки и документы для организации моего обучения: план, задания, записи о навыках и результатах занятий. Они помогают Codex учитывать, что мы уже разобрали и к чему нужно вернуться на следующем уроке.

Ещё сделала первый шаг к серверной части приложения: создала отдельный проект на Java 25 и Spring Boot с Maven, добавила Spring Web и Lombok. Сервер запустился на порту 8080.

Пока это каркас проекта: своих обработчиков запросов и связи с интерфейсом ещё нет. Разбор созданных файлов, проверку остановки и повторного запуска оставила на следующее занятие.
