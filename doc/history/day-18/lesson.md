## Объяснение и ближайшая практика

Переменная позволяет обращаться к значению по имени: использовать его в вычислении, проверке или отображении. Как записанная мерка «длина юбки — 60 см»: название помогает понять смысл числа. Аналогия объясняет имя и значение, но не правила языка; в коде единица измерения не появляется автоматически.

```js
const skirtLength = 60
const cutLength = skirtLength + 4
```

`const` объявляет переменную, которой нельзя присвоить другое значение. `skirtLength` — имя, `60` — начальное числовое значение; `=` здесь задаёт его при объявлении. Во второй строке читается значение `skirtLength`, к нему прибавляется `4`, результат `64` становится значением `cutLength`. Здесь нет HTML; вычисление уже имеет смысл само по себе. Имена записаны в `camelCase`; `skirtLength` — длина юбки, `cutLength` — длина отреза.

Для двух чисел `+` выполняет сложение; в разобранном вводном примере с числом и строкой число преобразуется в строку и получается соединение `'3'` и `'2'`. Поэтому результаты — число `5` и строка `'32'`.

В этом проекте `npm run dev` выполняет сценарий `dev` из `package.json`, где указано `vite`. Запускается сервер разработки Vite, который отдаёт материалы фронтенда браузеру. React-код интерфейса выполняется в браузере. Будущий сервер Java/Spring запускается отдельным процессом. Ссылка в терминале помогает найти адрес; работа интерфейса дополнительно проверяется в браузере.
