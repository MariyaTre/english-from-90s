# Присваивание: знак `=`

**Взять значение справа от `=` и записать его в переменную слева.** Если справа вычисление — сначала выполнить его.

Пример внутри `main`:

```java
int length = 10;
int savedLength = length;
length = length - 3;
```

1. `int length = 10;` — создать переменную `length` для целого числа и записать в неё `10`. `length` означает «длина».
2. `int savedLength = length;` — создать переменную `savedLength` («сохранённая длина») и записать в неё текущее значение `length`: `10`.
3. `length = length - 3;` — взять прежнее значение `length`, вычислить `10 - 3`, затем записать результат `7` обратно в `length`.

Теперь `length` содержит **7**, а `savedLength` — **10**.

**Запомнить:** чтение значения не забирает его из переменной. Для этих целых чисел присваивание копирует текущее значение; постоянной связи между переменными не возникает.

## Из какого значения продолжать расчёт

Правая часть определяет, какое число берём для вычисления. Для следующего изменения текущей длины нужно прочитать текущую длину.

Например, после трёх строк выше `length` равна 7, а `savedLength` — 10. Если внутри того же `main` выполнить `length = length - 2;`, получим 5: оба уменьшения учтены. Если вместо этого выполнить `length = savedLength - 2;`, получим 8: расчёт начнётся заново от сохранённых 10, и прежнее уменьшение на 3 в результат не войдёт.

Обе записи допустимы в Java. Выбор зависит от задачи: продолжить текущий расчёт или пересчитать от сохранённого значения. Когда текущее и сохранённое числа совпадают, оба варианта могут дать одинаковый результат.
