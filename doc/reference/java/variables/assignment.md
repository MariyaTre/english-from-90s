# Присваивание: знак `=`

**Взять значение справа от `=` и записать его в переменную слева.** Если справа вычисление — сначала выполнить его.

Пример внутри `main`:

```java
int length = 10;
int savedLength = length;
length = length - 3;
```

1. `int length = 10;` — создать переменную `length` для целого числа и записать в неё `10`. `length` означает «длина».
2. `int savedLength = length;` — создать переменную `savedLength` («сохранённая длина») и записать в неё текущее значение `length`: `10`.
3. `length = length - 3;` — взять прежнее значение `length`, вычислить `10 - 3`, затем записать результат `7` обратно в `length`.

Теперь `length` содержит **7**, а `savedLength` — **10**.

**Запомнить:** чтение значения не забирает его из переменной. Для этих целых чисел присваивание копирует текущее значение; постоянной связи между переменными не возникает.
