Длина ткани и припуск передаются в расчёт. Посмотрим, где появляются параметры, куда возвращается число и когда оно попадает в консоль.

Начинаем в main

Локальные переменные ещё не объявлены. Метод addAllowance описан, но его ещё не вызывали.

Код примера

Внутри main; заголовок точки входа опущен.

  1. int fabricLength = 12;
  2. int allowance = 3;
  3. int cutLength = addAllowance(fabricLength, allowance);
  4. System.out.println(cutLength);

Отдельный метод того же класса, вне main:

  1. static int addAllowance(int length, int extra) {
  2.   return length + extra;
  3. }

Класс опущен. Подсвечено действие разбираемого шага; порядок записи методов не задаёт порядок вызовов.

Перед следующим шагом предскажи, какие значения изменятся и появится ли вывод.

Граница модели. Показаны логические состояния, а не физические ячейки RAM и не точные остановки отладчика. Для int передаётся копия числового значения; объекты здесь не рассматриваются.

Это иллюстрация с заранее проверенными состояниями, не запуск Java. Возврат числа, присваивание и вывод — разные действия. Недоступность параметра после вызова не означает немедленное стирание физической памяти.
