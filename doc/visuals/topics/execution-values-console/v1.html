Число сохранили. Почему его ещё не видно?

Разберём пять действий внутри main. У каждого — своя работа: создать переменную, сохранить число, изменить его или вывести в консоль. Сначала преподаватель показывает и объясняет переход; угадывать незнакомое не нужно.

Пример из жизни: две записи одной мерки

Представь: в рабочем блокноте записана мерка — 10 сантиметров. Перед уточнением ты переписываешь число на отдельный листок. Потом исправляешь мерку в блокноте на 7. На листке по-прежнему 10: исправление одной записи не переписывает другую.

В коде length — рабочая мерка, savedLength — сохранённая мерка. Английское length означает «длина», saved — «сохранённая». Здесь обе мерки — целые числа сантиметров.

Граница сравнения: это записи чисел, а не сама ткань. Переменные не являются бумажками внутри компьютера. Мы показываем их текущие значения, а не устройство оперативной памяти.

Синий — выполненное действие Зелёный — итог вычисления Консоль — отдельный вывод

Рабочий пример Java

Полный пример для файла FabricExample.java. Строки 3–7 — действия, которые будем разбирать. Подсветка означает: действие уже выполнено.

  1. public class FabricExample {
  2. public static void main(String[] args) {
  3. int length = 10;
  4. int savedLength = length;
  5. length = length - 3;
  6. System.out.println(savedLength);
  7. System.out.println(length);
  8. }
  9. }

Ожидаемый вывод всей программы: сначала 10, на следующей строке 7. Ниже можно увидеть, когда появляется каждая строка.

Консоль: что программа вывела



Консоль — область, где виден вывод запущенной программы. Это не место, куда в этом примере нужно вводить команды. Строки println пишутся в редакторе кода.










Кнопки перелистывают учебную схему. Они не запускают Java и не заменяют запуск в IDEA.




Разбираем обозначения без спешки


int — тип для целого числа. int length = 10; объявляет переменную с именем length и начальным значением 10. Имя помогает обращаться к этому значению позже. Точка с запятой завершает инструкцию.


= — присваивание: сначала вычисляем правую часть, затем записываем результат в переменную слева. В length = length - 3; справа сначала читается прежнее значение 10, получается 7, затем 7 записывается в length. Знак - обозначает вычитание.


int savedLength = length; читает число, которое сейчас находится в length, и сохраняет его в новой переменной. Для этих целых чисел это копия значения, а не связь, которая обновляет обе переменные.


System.out.println(...) выводит указанное в круглых скобках значение и переходит на новую строку. Само создание или изменение переменной ничего не печатает. Память нужна программе для работы со значениями; вывод на экран — отдельное действие.


Что за строки окружают наши пять действий?

public class FabricExample объявляет класс — именованный блок, в котором размещён этот код. public означает доступность извне, class — объявление класса, FabricExample — выбранное имя. Фигурные скобки показывают начало и конец блока.


main — метод, с которого начинается выполнение при таком запуске этого класса. static позволяет запустить его без создания отдельного объекта класса; void означает, что метод не возвращает значение вызывающему коду. String[] args — место для текстовых аргументов запуска, в нашем расчёте они не используются. Объекты, массивы и возврат сейчас осваивать не требуется: преподаватель объясняет назначение оболочки, а наша цель — пять действий внутри неё.


В этой простой последовательности действия выполняются по порядку. Нельзя обобщать это на все строки любого Java-файла: другие методы выполняются при вызове, а условия и циклы меняют путь выполнения.
