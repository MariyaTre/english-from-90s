# Авторская проверка схемы v1

- Дата: 12 октября 2026 года.
- Проверены: [схема](v1.html) и [шаблон версии 1](../../template.html).
- Среда: локальный Google Chrome через Playwright; открытие HTML по `file://`, без запуска приложения и Java.
- Ширины окна: 1280 и 360 px; проверены все шесть состояний (0–5), начало/конец, переходы в обе стороны, запуск кнопки клавишей Enter.
- На каждом шаге сопоставлены значения main, наличие параметров текущего вызова, вывод консоли и доступность переходов.
- Проверено отсутствие горизонтального переполнения, обрезки ячеек, ошибок JavaScript и внешних HTTP-запросов.
- Снимки обычной и узкой страницы просмотрены агентом. После первого просмотра увеличена ширина колонки значений и визуально отделён метод класса от фрагмента main; проверки выполнены повторно.
- Модель: вызов получает два числовых значения 12 и 3, возвращает 15; после возврата main получает cutLength = 15, исходные значения сохраняются; вывод появляется только после println. Шаг возврата объединяет вычисление, возврат и присваивание — это явно обозначенная учебная последовательность, не точная трасса остановок отладчика.
- Результат: браузерные и визуальные проверки пройдены. Выполнение Java не проверялось; страница показывает подготовленную модель.
- Применение Машей: не проверено. Это образец формата для куратора, а не проведённое занятие или доказательство навыка.

При содержательной правке повторить проверку и обновить эту запись. Факт просмотра агентом не заменяет проверки понимания Машей.
