# Действующий замысел и состояние проекта

## Что создаём

«Английский из 90-х» — приложение для изучения английского в стиле старого компьютера. Пользователь организует свои слова в папках и документах, затем занимается по ним. Название репозитория — `english-from-90s`.

### Рабочий стол и документы

- Синий фон, нижняя панель, ретро-иконки и объёмные окна.
- Пользователь сам создаёт и называет папки и документы. Обязательных специальных разделов нет.
- Ярлыки автоматически располагаются сверху вниз, затем следующей колонкой справа.
- Нажатие на изображение открывает объект; на подпись — начинает переименование.
- Окна показываются поверх рабочего стола. Home закрывает открытые окна.
- Папки могут содержать другие папки и документы. Создание задумано через контекстное меню на рабочем столе и внутри папки.
- Документ содержит собственные слова. Переименование сохраняет содержимое. Для удаления папок и документов предусмотрена корзина; её точное поведение ещё нужно определить.

### Учебный документ

Верхняя панель содержит «Играть», «Тренировка», последовательность тренировки и карандаш. Ниже расположена таблица, внизу — «Добавить» и «Удалить».

| Столбец таблицы | Назначение |
|---|---|
| Номер | Порядковый номер строки |
| Рука | Элемент управления будущим перемещением строки |
| Английский | Слово или выражение |
| Русский | Перевод |
| Английский пример | Пример употребления |
| Русский пример | Перевод примера |

Нужны добавление, редактирование, удаление и изменение порядка строк. Минимальный первый цикл сохранения может охватывать только слово и перевод; остальные поля подключаются постепенно, без отмены общего замысла.

Ближайший серверный результат — сохранить английское слово и русский перевод через `POST /words`, получить сохранённые записи через `GET /words` и увидеть их в таблице `words` через Database в IDEA. У записи служебный `id`. Планируемые части: `WordController`, `WordService`, `WordRepository` на Spring Data JPA и Entity `Word` в подпакете `words`. Это требования к предстоящей работе, таких классов пока нет. Liquibase с SQL предложен как возможный способ создания таблицы; окончательное решение принимается перед изменением схемы.

### Тренировка и игра

В замысле диктанта перед пользователем находится мама или бабушка: за ошибку — шуточный «лещ» рыбой, за правильный ответ — петушок на палочке. Правила проверки, выбор персонажа и визуальные реакции разрабатываются после рабочего учебного цикла.

### Решения перед соответствующей функцией

Не нужно задавать Маше все эти вопросы перед первым занятием. Уточнять по мере приближения задачи:

- Обязательные поля слова, пустые значения, повторяющиеся слова.
- Выбор строки, назначение карандаша, сохранение и отмена редактирования.
- Допустимые имена, совпадающие названия, возвращение из вложенной папки.
- Поведение корзины, восстановление и судьба содержимого удалённой папки.
- Вид перемещения: порядок, перенос между папками или свободные координаты.
- Назначение EN, инструментов, времени и логотипа.
- Различие игры и тренировки, последовательность слов и правила ответа.
- Необходимость нескольких окон, изменения размеров и сворачивания.
- Мобильная платформа, состав первой публикуемой версии, площадка размещения и необходимость регистрации.

## Техническое направление

| Область | Соглашение |
|---|---|
| Фронтенд | Существующий React + Vite, JavaScript/JSX; постепенное выделение компонентов по мере работы над функциями |
| Бэкенд | Java 25 + Spring Boot 4.1.1 + Maven; отдельный репозиторий `D:\Projects\english-from-90s-back` по решению Маши |
| База | PostgreSQL как текущий учебный выбор; подключение небольшими шагами |
| Локальное окружение | `_local/` внутри серверного репозитория |
| Compose | `_local/docker/docker-compose.yaml` внутри серверного репозитория |
| Мобильный клиент | Отдельная ранняя проба на том же API; платформа выбирается перед ней |
| Документация | Маршрут, запуск, договорённости и учебные записи — внутри `doc/` |

Сервер и локальная инфраструктура создаются Машей в ходе обучения. Используются Java 25, Spring Boot 4.1.1 и Maven (Wrapper 3.9.16). Подключены Spring Web и Lombok; аннотации Lombok пока не используются. Фронтенд и сервер ведутся в отдельных репозиториях по явному решению Маши. Учебные записи по обеим частям остаются в `doc/` фронтенд-репозитория. В день 19 создан Compose для PostgreSQL 17 с помощью мужа; подключение Java к базе пока не настроено.

Соглашения об именах, компонентах и размещении новых файлов находятся в [code-quality.md](code-quality.md). Они задают направление самостоятельной работы; карта реализации ниже описывает только фактически существующие файлы.
