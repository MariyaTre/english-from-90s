# Документация и обучение

Маша пишет приложение сама. Codex готовит занятия, помогает разобраться и ведёт эти записи. Для начала достаточно написать: «Хочу позаниматься» или «Давай следующий урок». В конце — «Готово» или «На сегодня всё». Специальные команды не нужны.

Занятия хранятся в `history/day-N/` и создаются по запросу Маши. [День 19](history/day-19/result.md) завершён с частичным результатом: подготовлены PostgreSQL и настройки Java-приложения, создан первый диагностический компонент. Следующий номер — 20; продолжение — сохранение и получение слова через API и базу. Точная точка продолжения — в [указателе истории](history/README.md).

При завершении занятия Codex сохраняет в папке дня также `youtube.md`: название и описание ролика. Полный текст показывает прямо в диалоге, чтобы Маша могла его скопировать. Файл остаётся в истории; публикацией занимается Маша.

## Как поддерживать порядок

- Правила поведения живут в корневом `AGENTS.md`, подробная методика — в `learning-process.md`. Шаблоны задают структуру записи, а не дублируют методику.
- Требования к приложению хранятся в `project.md`, учебный маршрут — в `plan.md`. Не копировать полный перечень требований в каждый урок.
- Реестр навыков хранит текущую оценку со ссылкой на наблюдение. Подробности конкретной попытки относятся к результату соответствующего дня.
- План и требования редактируются на месте: без зачёркнутых вариантов, разделов «раньше было» и журнала правок. История занятий нужна для обучения и сохраняется отдельно.
- Документация развивается во время доступного Codex диалога. Здесь нет фонового наблюдения за Машей или доступа к недоступным старым чатам.

Корневой файл явно предписывает читать документацию: произвольные файлы в `doc/` не следует считать автоматически загруженными инструкциями. Механизм инструкций описан в [официальной документации Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md).
