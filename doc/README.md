# Документация и обучение

Маша пишет приложение сама. Codex готовит занятия, помогает разобраться и ведёт эти записи. Для начала достаточно написать: «Хочу позаниматься» или «Давай следующий урок». В конце — «Готово» или «На сегодня всё». Специальные команды для занятия не нужны. Муж может начать сообщение словами «я муж» и свободно описать совместную практику; агент сохранит наблюдения по контракту.

Начало нового контекста — [короткая точка входа](session.md) и [порядок объяснения](explanation-first.md), затем только нужные записи по AGENTS.md. Всю карту и методику на каждом сообщении перечитывать не нужно.

## Как поддерживать порядок

- Правила поведения живут в корневом `AGENTS.md`, порядок занятий — в `learning-process.md`, механизм диагностики и практических остановок — в `practice.md`. Шаблоны задают структуру записи, а не дублируют методику.
- Требования к приложению хранятся в `project.md`, учебный маршрут — в `plan.md`. Не копировать полный перечень требований в каждый урок.
- `skills/review-queue.md` хранит точные индексы и состояния повторений; проверять открытые записи с индексом ≤ текущего. Реестр навыков хранит текущую оценку со ссылкой на наблюдение. Подробности попытки относятся к результату соответствующего дня. Развёрнутое внешнее сообщение вне урока можно сохранить в `skills/observations/` с датой и источником; ради него учебный день не создавать.
- План и требования редактируются на месте: без зачёркнутых вариантов, разделов «раньше было» и журнала правок. История занятий нужна для обучения и сохраняется отдельно.
- HTML-схемы в `visuals/` агент создаёт сам по отдельному разрешению куратора. Они автономны, используют один визуальный язык и проходят проверку браузером; показанные версии сохраняются по темам. Код заданий и приложения по-прежнему пишет Маша.
- Документация развивается во время доступного Codex диалога. Здесь нет фонового наблюдения за Машей или доступа к недоступным старым чатам.

Корневой файл явно предписывает читать документацию: произвольные файлы в `doc/` не следует считать автоматически загруженными инструкциями. Механизм инструкций описан в [официальной документации Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md).
